# Ход разработки
## 1. Основа расчёта — завершено
Каталог Hunter, издание 41, стр. 53: 90 табличных сочетаний для MP-1000, MP-2000 и MP-3000 (радиус в метрах, расход в л/мин). Для каждой записи известны сектор и давление на сопле. В руководстве по проектированию разделы на PDF-листах 8–10 описывают перекрытие, деление на зоны и подбор труб. Исходники клиентов и оригиналы PDF хранятся отдельно от кода.
Проверка: node --test tests/catalog.test.mjs.
Следующий этап: загрузка нового изображения, автоматическая разметка и указание масштаба.

## 2. Загрузка изображения и разметка — завершено
Браузер обрабатывает новые JPG, PNG и WebP локально. Выделены связные цветные области; доступны оригинал, наложение, исправление класса и измерение по двум точкам. Распознавание цвета приблизительное. Пример — отдельный синтетический план. Сборка в один HTML: python tools/build.py. Проверка: node --test tests/*.test.mjs.
Следующий этап: предварительная расстановка по подтверждённому масштабу и расчёт расхода.
Синхронизация: GitHub ответил 403 при создании дерева и при записи файла. Коммиты сохраняются в git bundle, журнале и версионном архиве до получения рабочего доступа.
