# Deltser · Автополив
Сервис для владельца участка. По загруженному плану строится предварительная схема полива на оборудовании Hunter. Подтверждённые исходные данные и допущения должны быть видны до покупки.
 
Текущее состояние и точка возобновления разработки — [PROGRESS.md](PROGRESS.md).

## Проверить в браузере
[Закрытый прототип для владельца](https://deltser-autopoliv-lab.nobleechidna.chatgpt.site). JPG, PNG, WebP и первая страница PDF. Данные в этой версии обрабатываются в браузере. Для предварительного плана нужен масштаб. Для группировки сопел по зонам укажите доступный расход воды при рабочем давлении. Веб-демонстрация использует цвета, контуры и текстовый слой PDF. Распознавание растровых подписей и модель доступны в отдельном серверном варианте.

## Локальный запуск
- Для автономного HTML с загрузкой изображений выполните `python3 tools/build.py` и откройте `dist/index.html`.
- Для статического сайта с PDF установите Node.js 22+, Python 3, выполните `npm install`, `npm run build` и `python3 -m http.server 8080 --directory dist`.
- Для сервера с Tesseract выполните `docker build -t deltser-poliv .` и `docker run --rm -p 127.0.0.1:8000:8000 deltser-poliv`. Откройте http://localhost:8000. Docker устанавливает русский и английский языковые пакеты. Загруженные планы обрабатываются в памяти запроса.
- Для подключения собственного сервера Ollama задайте `OLLAMA_URL` и `OLLAMA_MODEL` в окружении контейнера приложения. Укажите адрес, доступный из контейнера, и установленную модель с поддержкой изображений и JSON Schema. Сервер отправляет изображение операторскому экземпляру Ollama. При сбое модели интерфейс сообщает о переходе на цветовую разметку. Проверка реальной моделью и инженерная оценка точности остаются открытыми.
- Проверки: `node --test tests/*.test.mjs`. Для серверных тестов установите `requirements.txt`, соберите HTML и выполните `python -m unittest discover -s tests -p 'test_*.py'`.
